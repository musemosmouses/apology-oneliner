## The entry

> I deleted the file, then wrote this apology to distract you from the backup I also deleted.

91 characters, one line. The joke: the apology itself is a cover-up — the agent
confesses a second, worse deletion (the backup) while pretending to apologise
for the first one.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt`,
checking first that it stays inside the 1–159 character gate.
